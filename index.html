How it works

SHA-1 / SHA-256 / SHA-384 / SHA-512 use your browser’s built-in Web Crypto API. MD5 and CRC32 use small bundled JavaScript implementations (no CDN). Files are read in 4 MiB chunks inside a Web Worker so the page stays responsive; MD5 and CRC32 stream chunk-by-chunk, while Web Crypto needs the whole file in memory, so SHA hashes are limited to files under 2 GiB. Text is hashed as UTF-8 bytes. MD5 and SHA-1 are fine for checksums but are not collision-resistant — prefer SHA-256+ for security.
